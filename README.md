# chatbot-api--
OpenRouter ai 问答助手,爬取网站的内容，通过Openrouter，回答问题。
本项目是一个基于 Spring Boot 构建的智能问答聊天机器人 API，核心宗旨是通过自动化手段获取社区问题并调用 AI 大模型生成答案，从而大幅降低人工维护 FAQ 的成本，提升知识库的响应及时性与覆盖面。
项目采用领域驱动设计（DDD）架构，代码结构清晰，高内聚低耦合，包含四个核心模块：
在领域层（Domain），实现了知识星球（ZSXQ）的核心数据模型与服务，并对 AI 大模型的调用（如 OpenRouter、ModelScope）进行了抽象与聚合，支持不同模型的灵活切换；在应用层（Application），通过引入定时任务（如 ChatbotSchedule）来实现业务的自动化流转与数据处理；而接口层（Interfaces）**则对外暴露 RESTful API 并配备了完善的单元测试。
目前，项目已成功实现从知识星球自动拉取未回答问题，并对接 OpenRouter 和 ModelScope 进行多模型问答与自动回复。整体工程采用 Maven 构建，严格遵循 Java 编码规范，具备极佳的扩展性，可轻松接入其他内容源或前沿的大模型服务。总体而言，这是一款高度实用的智能客服辅助工具，非常适用于社群运营与自动化知识管理场景。
